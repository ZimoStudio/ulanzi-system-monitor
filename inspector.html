Action
Press this key to open the dashboard in your browser (default address http://127.0.0.1:39170). Charts, per-core bars, top processes and all display settings live there. The key shows live CPU usage.
Top Process
Sort by
Press the key to switch between CPU and RAM. This setting is the starting view. Processes with the same name (e.g. all Chrome processes) are added together. Refreshes every 5 s by default because reading all processes is heavier.
R = read speed, W = write speed (whole PC, all drives).
One bar per CPU thread. With more than 16 threads, neighbouring threads are averaged.
Ping
Host
IP or domain, e.g. 8.8.8.8 or google.com. Warning / critical are in milliseconds.
For Battery, warning / critical are the levels it falls below (default 30% and 15%). Charging shows cyan when Color = Auto.
Temperature
Sensor
LibreHW URL
If the PC does not expose CPU temperature (common on Windows), run LibreHardwareMonitor with Options → Remote Web Server → Run. The plugin finds it automatically on port 8085; fill the URL only if you changed it.
